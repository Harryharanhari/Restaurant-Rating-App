# 🍽️ Restaurant Rating Prediction App

A Machine Learning–powered web application that predicts **restaurant ratings** based on key attributes such as votes, price range, city, and cuisine.  
The model is deployed as an interactive **Streamlit web app**, enabling real-time predictions through a user-friendly interface.

---

## 🚀 Live Application

🔗 **Streamlit App:**  
https://restaurant-rating-app-ugyen5yu5zjxehuyhypg4n.streamlit.app/

---

## 📌 Project Overview

This project was developed as part of a **Machine Learning internship** to demonstrate:
- End-to-end ML workflow
- Model training and serialization
- Deployment of ML models as web applications

The application allows users to select restaurant details and instantly receive a predicted rating.

---

## 🧠 Machine Learning Approach

- **Problem Type:** Regression  
- **Algorithm Used:** Linear Regression  
- **Target Variable:** Aggregate Restaurant Rating  

### 🔧 Features Used
- Number of Votes  
- Price Range  
- City  
- Cuisine  

Categorical features were encoded using **Label Encoding**, and the trained model was serialized using **pickle**.
